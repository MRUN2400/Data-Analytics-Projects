# Customer Purchase Behavior Analysis

##  Project Overview

This project analyzes customer purchasing behavior using **Python, SQL, and Power BI**. The workflow includes data cleaning, SQL-based analysis, and interactive dashboard visualization to uncover insights related to customer segments, loyalty, and purchasing trends.
# 🛠️ Tools Used

* Python
* MySQL
* Power BI
* GitHub
#  Project Workflow

### 1. Data Preparation & Modeling (Python)

* Cleaned and transformed raw customer data for analysis.

### 2. Data Analysis (SQL)

* Performed analytical queries to identify customer behavior, purchase trends, and loyalty patterns using joins, CTEs, aggregate functions, and window functions.

### 3. Visualization & Insights (Power BI)

* Built interactive dashboards to visualize customer trends, purchase frequency, and business insights.
